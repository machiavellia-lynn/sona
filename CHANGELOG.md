# Changelog

## 1.0.0

First public release.

- Pill around the camera cutout with animated mascot eyes (follow touch, moods, idle behaviours).
- Notification pop-ups with reply / actions, queue, conversation merging, quiet hours, per-app muting.
- Music player card for any media app, with seek bar, custom actions and an equalizer in the pill.
- Timer and stopwatch with laps, kept across restarts.
- System event pills: Wi-Fi, mobile data, Bluetooth, charging, battery, ringer, airplane, power saving.
- Call indicator with duration, live activities, torch, camera / microphone privacy dots.
- Quick Settings tile. Optional `adb` grant unlocks the Start button and hides One UI's own heads-up pop-ups.
